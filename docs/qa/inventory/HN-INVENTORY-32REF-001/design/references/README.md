# HOA NAM — Tồn kho & Đối soát — Bộ đã duyệt

Ngày phê duyệt: 29/10/2026.

Gói gồm đúng 32 ảnh PNG bản cuối: 16 màn/trạng thái, mỗi loại có Desktop và Tablet dọc. Không bao gồm ảnh trung gian hoặc các bộ thiết kế cũ.

- Đọc PROMPT_S00-1.md để giao triển khai đầy đủ.
- IMAGE_INDEX.md liệt kê từng ảnh và kích thước gốc.
- MANIFEST.csv ghi kích thước, dung lượng và SHA-256 để kiểm tra đúng tệp.
- Thư mục Desktop và Tablet chứa ảnh đánh số 01–16 tương ứng.

Ảnh được giữ nguyên byte gốc, không nén lại hoặc phóng lớn giả. Đây là bản thiết kế tham chiếu, không phải screenshot sản phẩm đã triển khai hoặc bằng chứng API hoạt động. Các sai khác nhỏ của hình sinh phải được chuẩn hóa theo prompt và Design System; margin/padding cần đo trên UI chạy thật.
