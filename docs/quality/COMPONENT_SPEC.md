## Shared state contract

For every applicable interactive component capture default, hover, focus-visible, active/selected, disabled, read-only and pending/loading. Include error/validation and empty/no-results/denied where meaningful. A non-applicable state must be marked N/A with a reason; absence of an image is not N/A. Keyboard operation, accessible naming, focus visibility, long content and locale/theme reflow are acceptance requirements. Permission logic, query/sort, validation and state transitions remain caller-owned.
